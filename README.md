# IT Helpdesk System
A full-stack IT Helpdesk System built with Python and FastAPI.

Users (Two types)
Employee
Support Staff

Employee can:
Log in
View dashboard
Create support ticket
View own tickets
View ticket details
Add comments
Close their ticket

Support Staff can:
Log in
View all tickets
View ticket details
Change ticket status
Change priority
Assign tickets
Add resolution notes
